## Quick example

A self-contained introductory example is available in
[`notebooks/inf_active_colab_demo.ipynb`](notebooks/inf_active_colab_demo.ipynb).

It demonstrates the workflow on a simple test problem (Poisson control from the paper):
sampling function-valued inputs, computing functional gradients, estimating the
active subspace operator, and visualizing its leading eigenfunctions.
